# Magneetar iOS App

iOS companion app for the Magneetar anti-theft tracking system.

## Status

🚧 **Planned** - iOS development is scheduled for Milestone 5 (Weeks 15-20)

## Features (Planned)

- Real-time device tracking
- Command relay via push notifications
- Sentinel AI theft detection
- Guardian Network participation
- Evidence capture (photos, audio)
- Geofence monitoring

## Technical Requirements

- iOS 15.0+
- Swift 5.9+
- Xcode 15.0+
- Swift Package Manager

## Architecture

The iOS app will follow the same architecture as the Android app:

- **Core Location** for GPS tracking
- **Background Tasks** for periodic location updates
- **Push Notifications** for command delivery
- **Core Data** for local storage
- **URLSession** for API communication

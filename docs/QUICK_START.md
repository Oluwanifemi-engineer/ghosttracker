# Magneetar — Quick Start (for testers)

## Install (2 minutes)

1. Download the APK file we sent you
2. Open it → tap "Install"
3. If prompted, enable "Install from unknown apps" for your browser/file manager
4. Open Magneetar from your app drawer

## Set up (1 minute)

1. Tap **Sign Up**
2. Enter your email + a password
3. Grant permissions when prompted (location, camera, microphone, notifications)
4. Done — the app runs silently in the background

## Verify it works

1. Go to **app.magneetar.me** on any browser
2. Log in with the same email/password
3. You should see your phone on the map within 30 seconds

## What happens now

- Your phone reports its location every 3 seconds (you won't notice)
- If someone tries to steal it, the app detects it and captures evidence
- You can lock, alarm, or locate it from the dashboard anytime

## Test it (optional, but encouraged)

From the dashboard, try:
- **Siren** — makes your phone play a loud alarm (good for finding it under couch cushions)
- **Lock** — locks the screen with a custom message
- **Photo** — takes a front-camera photo silently

## Got problems?

- App not showing on map? → Check location permissions are set to "Allow all the time"
- Battery draining? → It shouldn't, but tell us if it is
- Something else? → WhatsApp us in the group
